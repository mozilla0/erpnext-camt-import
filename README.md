# Bank Import CH

CAMT.053 Bank Transaction Import für ERPNext v16 – optimiert für Schweizer Banken.

## Features

- Import von CAMT.053 XML-Dateien (alle gängigen Versionen: 001.02 bis 001.11)
- Übersichtliche Darstellung aller importierten Transaktionen
- Bestätigung einzelner Transaktionen (Ausblenden nach Bestätigung)
- Filtermöglichkeiten nach Konto, Datum, Status
- Unterstützung für mehrere Bankkonten

## Installation

```bash
bench get-app https://github.com/your-org/bank_import_ch.git
bench --site <sitename> install-app bank_import_ch
```
